Focus

One-time setup for the Dynamic Island
  1. Open the Shortcuts app and tap +.
  2. Name it exactly Jarvis Focus.
  3. Add the action Start Timer. Tap its time and choose Shortcut Input, set to minutes.
  4. Done. When you start a focus, Shortcuts opens for a second and the timer appears in the Dynamic Island.

Lock-screen notifications

Reminders and a 7 AM school-day brief, even when your PC is off.

  1. Install ntfy (free) from the App Store. Open App Store
  2. Copy your Jarvis channel name:
  3. In ntfy tap +, paste it as the topic, leave the server as ntfy.sh, tap Subscribe, and allow notifications.
  4. It should pop up in a few seconds.

Notification text goes through ntfy unencrypted (it has to be readable on your lock screen). The channel name is long and random, so keep it to yourself.
